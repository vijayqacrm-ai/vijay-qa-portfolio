# Vijay Krishna Parvathaneni — QA Portfolio

Static portfolio website for GitHub Pages.

## Local preview
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, e.g. `qa-portfolio`.
3. Upload the contents of this folder.
4. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
5. GitHub will provide the public portfolio URL.
